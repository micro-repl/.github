# Micro REPL

**A free, open-source MicroPython IDE for Android, Desktop and the Web**

Plug a MicroPython board into your phone or computer over USB and get a **live REPL**,
a **file explorer** for the board's storage and a **code editor**.

## 📱 💻 🌐 One app, every platform

The same app and the same layout on Android, Windows, macOS, Linux and the browser.
It works with most boards that run MicroPython, such as the Raspberry Pi Pico and the ESP32.

## 🌐 Try it in your browser

[micro-repl.github.io](https://micro-repl.github.io/) runs the full IDE in your browser,
with nothing to install. It connects to your board through
[Web Serial](https://developer.mozilla.org/docs/Web/API/Web_Serial_API) in Chrome, Edge or Opera on desktop.
